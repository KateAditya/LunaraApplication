Lunara App

Premium Whitish Aesthetic Refactor

The Lunara app is being transitioned to a clean, minimal design. This refactor focuses on moving away from dark glassmorphism toward high-contrast, premium light surfaces.

Project Structure

lib/
├── core/
│   ├── constants/       # Global constants, colors, theme
│   ├── network/         # API clients
│   └── utils/           # Shared utility functions
├── features/
│   ├── auth/           # Login, Register, Forgot Password
│   ├── booking/        # Venue and Event bookings
│   └── user_profile/   # Profile settings and stats
├── shared_widgets/      # Common UI (Buttons, Cards, Modals)
└── main.dart

Core Principles

  • Minimalism: High use of whitespace and subtle shadows.
  • Brand Consistency: Strict use of Violet/Pink gradients for primary actions.
  • Premium UX: Smooth transitions and high-quality typography (AllroundGothic & AloeVera).
